# Tic-Tac-Toe (Spring Boot)

Веб-приложение «Крестики-нолики» на Spring Boot: поле N×N с настраиваемой длиной выигрышной линии и компьютерный соперник на алгоритме минимакс.

> Проект в разработке.

## Технологии

- Java 21
- Spring Boot (Spring Web)
- Gradle (Kotlin DSL)
- JUnit 5

## Запуск

```bash
./gradlew bootRun
```

Приложение стартует на `http://localhost:8080`.

## Тесты

```bash
./gradlew test
```
